# Шрифты для PDF (кириллица).

DejaVuSans.ttf + DejaVuSans-Bold.ttf — из тестов fpdf2
(https://github.com/py-pdf/fpdf2/tree/master/test/fonts),
лицензия — DejaVu (свободная, см. https://dejavu-fonts.github.io/).
Встроены в бинарник через go:embed (core/export/pdf.go).
Перекачивать только при смене шрифта.
