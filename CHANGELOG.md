# Changelog

## [2.0.0] — 2026-10-11

Мажорный релиз: свойства партии на катушке и навигация по складу.

- Катушка — полноценная партия: производитель, цвет, плотность, диаметр
  живут на закупке (миграция с автопереносом); вес работ считается
  по физике привязанной катушки; у материала остались только код, тип
  и заметка, вес новых партий — 1000 г.
- Выбор цвета — с базовой палитрой под тип пластика, фаворитами и пипеткой.
- Отчёты: коды материалов и катушек кликабельны — переход на вкладку
  Материалы с раскрытием и подсветкой; счётчики живых и архивных катушек
  видны всегда.
- История: фиксированная узкая колонка чекбоксов.

## [1.4.18] — 2026-10-11

- Импорт материалов: табличный предпросмотр (код, № катушки, цена,
  существующие подсвечены) с чекбоксами — импортируются только отмеченные.
- Поле «Последние N» — одно на историю и материалы.
- Импорт строго последовательный: новый предпросмотр при висящем чужом
  запрещён (`ERR_PENDING_EXISTS`); «Отменить импорт» сбрасывает и материалы.
- В окнах предпросмотра — только просмотр и чекбоксы (одна кнопка «Закрыть»);
  применение — инлайн-кнопкой с числом отмеченных.

## [1.4.17] — 2026-10-11

- Катушки: заметка закупки; статус «В работе / В архиве» вместо флага расчётной.
- Материалы: средняя цена катушки в карточке; аккуратные плейсхолдеры цен.
- Заголовок dev-сборки показывает дату и время билда (пометка dev сохранена).

## [1.4.4] — 2026-10-10

- Импорт материалов понимает катушки: строки `КОД-N` группируются —
  один материал + катушки с номерами; дубль номера — ошибка.
- Архив — только уровень катушки: архивные партии скрыты из остатков
  и цен, чекбокс архива у материала убран (колонка в БД мертва).
- Код материала правится с перепривязкой истории.
- Импорт материалов из CSV (dry-run → применить): только новые коды,
  цена — в первую катушку; существующие не трогаются.

- Номера катушек (1, 2, 3...): имя файла `деталь_PETG-NIT-BLACK-1_2h10m.gcode`
  привязывает импорт (CSV и Moonraker) к материалу и именно этой катушке
  с её ценой; нет катушки — первая, нет материала — стаб. Старые коды
  без номера работают как раньше.

- Материал и катушки разделены: карточка материала — только пластик
  (производитель, тип, цвет...), цена живёт на катушках. Раскрытие «▸»
  показывает закупки: дата, цена, вес партии, остаток, бейдж «расчётная»
  (первая неархивная — по ней себестоимость). Новая катушка — с датой.
- Отчёт закупок теперь видит настоящие даты катушек.

- Закупки запчастей и ТО: блок в карточке каждого принтера (дата, наименование,
  цена, количество, авто-сумма, примечание); принтер с закупками не удаляется.
- Отчёт закупок в Отчётах: запчасти и пластик (по катушкам) с группировкой
  День/Неделя/Месяц/Год и строкой «Всего».

## [1.0.0] — 2026-10-08

Первый мажорный релиз. Приложение выросло из Excel-калькулятора в полноценную
программу — и по пути исправило его ошибки (лишние +24 ₽ к амортизации,
учёт только будних дней, захардкоженная плотность).

### Калькулятор

- Живой пересчёт себестоимости и цены: пластик, purge/брак, электричество,
  амортизация принтера, ТО, работа оператора и дизайнера, процент неудач,
  наценки, НДС, округление, деление на N копий на столе.
- Выбор заказчика и открытого заказа прямо в калькуляторе, добавление
  расчёта позицией в заказ и сохранение в историю.
- Подстановка работы из истории: материал, принтер, тарифы и ставки
  восстанавливаются из расчёта.

### История печати

- Импорт CSV принтера и Moonraker (Creality K1C) с предпросмотром (dry-run)
  и прогресс-баром.
- Сортировка по всем колонкам, поиск, фильтр по статусу, пагинация,
  настраиваемые колонки в Настройках.
- Правка работ, добавленных вручную, с автоматическим пересчётом
  себестоимости; удаление только ручных позиций.
- Пометки источника: CSV, Moonraker, вручную.

### Материалы и принтеры

- Материалы: коды, цены, плотность, цвета (пипетка, пресеты, фавориты),
  остатки катушек; удаление с защитой связанных данных.
- Принтеры: все характеристики, три метода амортизации (календарный
  по умолчанию), адрес Moonraker на каждый принтер.

### Заказы и отчёты

- Заказчики с заметками, заказы с названиями и автонумерацией по шаблону
  (`{YYYY}-{nnnn}` и другие токены — настраивается).
- Позиции, статусы на русском, оплаты, остатки; клик по долгу открывает заказ.
- Отчёты: выручка по месяцам, долги, топ материалов, загрузка принтеров.

### Данные и печать

- `backup.zip` в один клик (база + CSV), восстановление с проверкой.
- PDF-отчёты A4 из каждой вкладки с футером `nodeus.ru`.
- Печать любой вкладки через системный диалог.

### Пользователи и интерфейс

- Роли `admin/manager/viewer`, локальный вход, управление пользователями.
- Русский и английский без перезапуска, мультивалютность.
- Первый запуск — чистый (только `admin/admin123`), свои данные импортируются.
