# Обновление приложения

Встроенного автообновления нет (Wails v2 его не даёт из коробки).
Путь обновления — через бэкап, он же путь переноса на другой ПК:

1. В старой версии: Настройки → «Сохранить backup.zip».
2. Поставить новый `3dprint-calc.exe` рядом (или поверх, `app.db` не трогать).
3. В новой версии: Настройки → «Открыть бэкап (проверка)» → сверить счётчики
   (jobs/materials) → «Восстановить из бэкапа». Перезапуск не нужен.
4. Миграции БД применяются сами при старте (таблица `schema_migrations`).

Откат: предыдущий `app.db` остаётся в бэкапе; восстановление — той же процедурой.
CSV-выгрузки (`jobs.csv`, `materials.csv` внутри backup.zip) читаются без приложения.
