# Калькулятор стоимости 3D-печати

Локальное кроссплатформенное приложение для расчёта себестоимости и цены
FDM-печати: материалы, принтеры с амортизацией, история печати, заказчики,
 заказы, оплаты и отчёты. Один exe-файл (~5,5 МБ в UPX), данные — в `app.db`
рядом с программой. Без облаков и подписок, работает офлайн.

Стек: Wails v2 (Go) + Svelte + TypeScript + SQLite. Интерфейс — русский/английский.

## Возможности

- **Калькулятор**: живой пересчёт — пластик (с purge/браком), электричество,
  амортизация принтера, ТО, работа оператора/дизайнера, % неудач, наценки,
  НДС, округление, N копий на столе. Сохранение в историю, добавление в заказ.
- **История печати**: импорт CSV принтера и Moonraker (Creality K1C) с dry-run
  и прогрессом (цена и катушка — сразу при импорте), сортировка по всем колонкам, настраиваемые колонки, правка
  любых работ с автопересчётом, перенос в калькулятор (ставки не затираются).
- **Темы**: базовые светлая/тёмная + 32 пресета палитр IDE, экспорт/импорт в файл.
- **Калькулятор помнит значения**: ставки и параметры переживают вкладки
  и перезапуск.
- **Материалы**: коды, цены, плотность, цвета (пипетка, пресеты, фавориты), остатки катушек.
- **Принтеры**: характеристики, три метода амортизации (календарный по умолчанию),
  Moonraker-URL на принтер.
- **Заказы**: заказчики, позиции, статусы, оплаты и долги, автонумерация
  по шаблону (`{YYYY}-{nnnn}` и др.), дата и время оформления.
- **Отчёты**: выручка по месяцам, долги, топ материалов, загрузка принтеров.
- **Импорт/экспорт**: `backup.zip` в 1 клик, CSV истории/материалов, PDF-отчёты A4
  с футером `nodeus.ru` из каждой вкладки.
- **Пользователи и роли**: `admin/manager/viewer`, локальный вход (argon2id).

## Быстрый старт

1. Возьмите `3dprint-calc.exe` из папки `release/<версия>/<дата>/windows/amd64/`.
2. Запустите. Первый старт чистый: вход `admin` / `admin123` — смените пароль
   (Настройки → Пользователи).
3. Заведите принтер и материалы (или импортируйте CSV истории — материалы
   подтянутся сами), либо подключите Moonraker (`http://IP:7125` — со схемой!).
4. Считайте в калькуляторе, сохраняйте, собирайте заказы.

Подробно — [docs/HELP.md](docs/HELP.md). Что нового — [CHANGELOG.md](CHANGELOG.md).

## Сборка из исходников

Требуются Go 1.26+ и Node 24+.

```bash
# Desktop (Windows/Linux/macOS) — сам ставит npm-пакеты и строит frontend:
cd desktop && wails build

# Релиз в папки release/<версия>/<дата>/ (Windows-exe пакуются UPX):
go run ./tools/release -platforms windows/amd64
```

Проверки: `go build ./...`, `go vet ./...`, `go test ./...`, `gofmt -l .` (пусто),
`npm run check` в `desktop/frontend`.

## Структура

```
core/            чистый Go: calc (движок), models, store (интерфейсы),
                 importers, export (backup, CSV, PDF), moonraker, ordnum, auth, i18n
store-sqlite/    реализация Repository (pure Go, без CGO) + миграции
desktop/         Wails: тонкие биндинги + frontend Svelte+TS
server/          задел REST для Android (фаза 7)
migrations/      SQL-миграции (канон схемы)
tools/           seed, release, qrcode, dbcheck — только здесь
docs/            HELP, release, updating, api-contract, excel-reverse-engineering
```
