# Калькулятор стоимости 3D-печати

Локальное кроссплатформенное приложение для расчёта себестоимости и цены
FDM-печати: материалы, принтеры с амортизацией, история печати, заказчики,
 заказы, оплаты и отчёты. Один exe-файл (~5,5 МБ в UPX), данные — в `app.db`
рядом с программой. Без облаков и подписок, работает офлайн.

Стек: Wails v2 (Go) + Svelte + TypeScript + SQLite. Интерфейс — русский/английский.

## Возможности

- **Калькулятор**: живой пересчёт — пластик (с purge/браком), электричество,
  амортизация принтера, ТО, работа оператора/дизайнера, % неудач, наценки,
  НДС, округление. Сохранение в историю, добавление в заказ (цена — за копию).
- **История печати**: импорт CSV принтера и Moonraker (Creality K1C) —
  табличный предпросмотр значений с чекбоксами (импорт только отмеченных,
  дубли подсвечены, строго после предпросмотра и строго последовательно)
  и прогрессом (цена и катушка — сразу при импорте, лимит последних N),
  поиск и фильтры по статусу и источнику, массовое удаление и массовая
  правка чекбоксами, сортировка по всем колонкам, настраиваемые колонки
  (drag, ширины, 34 ключа), правка любых работ с автопересчётом, перенос
  в калькулятор (физика всегда, ставки — только из ручных/правленых).
- **Темы**: базовые светлая/тёмная + 32 пресета палитр IDE, экспорт/импорт в файл.
- **Калькулятор помнит значения**: ставки и параметры переживают вкладки
  и перезапуск.
- **Материалы**: коды-ключи для парсинга имён файлов; физика партии на катушке
  (производитель, цвет, плотность, диаметр, цена, остаток), цены, остатки катушек,
  цвета (пипетка, базовая палитра под тип пластика, пресеты, фавориты),
  импорт CSV с табличным предпросмотром и выбором строк.
- **Принтеры**: характеристики, три метода амортизации (календарный по умолчанию),
  Moonraker-URL на принтер (схема подставится сама), закупки запчастей/ТО.
- **Заказы**: заказчики, позиции (дробное qty, скидки), статусы, оплаты (правка/удаление)
  и долги, автонумерация по шаблону (`{YYYY}-{nnnn}` и др.), дата и время оформления,
  переходы из долгов и отчётов.
- **Отчёты**: выручка по месяцам, долги, топ материалов, загрузка принтеров,
  закупки и остатки катушек — с итогами, закупки в валюте базы (мультивалютность:
  базовая валюта + ручные курсы + снапшот курса), коды-ссылки на материалы.
- **Импорт/экспорт**: `backup.zip` в 1 клик (восстановление с предпросмотром состава),
  CSV истории/материалов, PDF-отчёты (альбомные A4 с футером `nodeus.ru`)
  из вкладок с кнопкой экспорта; печать — строго книжная.
- **Пользователи и роли**: `admin/manager/viewer`, локальный вход (argon2id);
  запись — `manager+`, пользователи — только `admin`.

## Быстрый старт

1. Возьмите `3dprint-calc.exe` из папки `release/<версия>/<дата>/windows/amd64/`.
2. Запустите. Первый старт чистый: вход `admin` / `admin123` — смените пароль
   (Настройки → Доступ → Пользователи).
3. Заведите принтер и материалы (или импортируйте CSV истории — материалы
   подтянутся сами), либо подключите Moonraker (`http://IP:7125` — со схемой!).
4. Считайте в калькуляторе, сохраняйте, собирайте заказы.

Подробно — [docs/HELP.md](docs/HELP.md). Что нового — [CHANGELOG.md](CHANGELOG.md).

## Сборка из исходников

Требуются Go 1.26+ и свежий Node LTS.

```bash
# Desktop (Windows/Linux/macOS) — сам ставит npm-пакеты и строит frontend:
cd desktop && wails build

# Релиз в папки release/<версия>/<дата>/ (Windows-exe пакуются UPX):
go run ./tools/release -platforms windows/amd64
```

Проверки: `go build ./...`, `go vet ./...`, `go test ./...`, `gofmt -l .` (пусто),
`npm run check` в `desktop/frontend`.

## Структура

```
core/            чистый Go: calc (движок), models, store (интерфейсы),
                 importers, export (backup, CSV, PDF), moonraker, ordnum, auth, i18n
store-sqlite/    реализация Repository (pure Go, без CGO) + миграции
desktop/         Wails: тонкие биндинги + frontend Svelte+TS
server/          задел REST для Android (фаза 7, пока каркас)
mobile/          задел Flutter-клиента (кода нет, контракт в docs/api-contract.md)
migrations/      SQL-миграции (канон схемы; копия в desktop/assets/migrations для go:embed)
tools/           seed, release, qrcode, dbcheck, rename_history — только здесь
utils/           локальный upx.exe для релизов (в git не идёт)
xlsx/ + csv/     legacy Excel и CSV-фикстура (источник сида)
docs/            HELP, release, updating, api-contract, excel-reverse-engineering,
                 workflow, material-colors
```
